Mode d’emploi — analyse 3D du Trail de Sadirac

1. Choisir un parcours

Dans le panneau de gauche, cochez ou masquez les traces 8 km, 12 km et 21 km. Le menu Profil analysé définit le parcours utilisé par le profil et le traceur.

2. Faire avancer le traceur

Utilisez le bouton ▶ pour lancer l’animation. Les boutons − et + permettent de ralentir ou d’accélérer le coureur. La vitesse 1× est volontairement plus lente pour faciliter la lecture de la carte. La barre de progression reste compacte dans la fenêtre du profil pour dégager la carte.

3. Déplacer manuellement depuis le profil

Cliquez dans le profil altimétrique ou dans la bande de pente. Maintenez le clic et faites glisser la souris. Sur téléphone, posez le doigt puis glissez. Le coureur se déplace immédiatement. Lorsque le suivi caméra est désactivé, vous pouvez déplacer librement la carte avec la souris pendant l’animation.

4. Comprendre les repères du profil

  • Repères kilométriques : grille verticale de distance.
  • Mini / maxi : points d’altitude minimale et maximale.
  • Pentes colorées : coloration selon l’intensité de la pente locale.

5. Fonds de carte et relief

Choisissez IGN Plan, IGN Topo J+1, OSM, OpenTopoMap ou une orthophoto. Activez le relief 3D, les courbes de niveau et les bâtiments OSM 3D selon le besoin. Le bouton caméra active ou désactive le suivi automatique du coureur. Le bouton de légende cartographique ouvre la liste des parcours directement depuis les commandes de la carte.

7. Tracer un segment libre

Cliquez sur Tracer un segment, puis choisissez deux points sur la carte. L’application calcule le profil altimétrique du segment. Utilisez Effacer segment pour revenir au parcours.

8. Lire les statistiques

Les panneaux indiquent la distance, l’altitude courante, les dénivelés cumulés, les pentes maximales, l’angle maximal et la source altimétrique utilisée. La réglette entre la carte et le profil permet de redimensionner verticalement les deux fenêtres.

9. Exporter les résultats

Vous pouvez enregistrer la carte, exporter le profil en image PNG, télécharger les données CSV ou générer un GPX enrichi avec les altitudes calculées.

Astuce : pour examiner précisément une montée, faites glisser le curseur directement dans le profil. Le suivi caméra est désactivé par défaut : la carte reste manipulable pendant que le coureur avance.
